1. 处理对象
待处理根目录：E:\本地图像、G:\本地图像
根目录下直接一级子文件夹，文件夹命名严格为日期格式：yyyy‑MM‑dd（每日自动生成）。
2. 日期文件夹删除规则
按文件夹名称的日期做判断，不读取文件修改时间。
保留 N 天，保留天数包含当天；计算阈值 = 当天日期 − (保留天数‑1)。
文件夹日期早于阈值：整体删除整个文件夹（连同内部所有图片 / 文件）。
文件夹日期大于等于阈值：保留不做任何处理。
3. 日期文件夹处理规则
日期文件夹为空：执行删除。
4. 异常容错规则
文件夹被程序占用、权限不足无法删除：跳过该项，记录日志，继续处理下一个文件夹，脚本不终止。
根目录不存在：记录警告日志，跳过该根目录。
当天的日期文件夹尚未生成：脚本正常结束，无报错。
E:\本地图像、G:\本地图像两个根目录本体严禁删除。
5. 日志要求
在脚本所在目录，自动生成与脚本同名的文件夹存放日志。
每天生成独立日志文件，日志文件名：yyyy‑MM‑dd.log，不无限追加在同一个日志。
日志内容：脚本起止时间、保留天数、每一条文件夹处理状态（待删除、成功删除、失败跳过、保留、警告）。
中文日志无乱码。
6. 运行与性能要求
大批量文件夹场景：禁止一次性预加载全部目录列表到内存，避免进程内存持续上涨直至占满内存；采用流式遍历。
